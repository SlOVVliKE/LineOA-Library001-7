ดับเบิลคลิก **`deploy-check-and-push.cmd`** → ตรวจ type → build → push ขึ้น GitHub

> ⚠️ **deploy จากเครื่องนี้โดยตรงไม่ได้** — นโยบาย Device Guard/WDAC บล็อก `workerd.exe`

## สิ่งที่ทำงานได้แล้ว

- ต้นทุนรายล็อต + ตัดสต็อกแบบ **FIFO** ใน Postgres transaction
- สิทธิ์ผู้ใช้ 5 role คุมด้วย **RLS ที่ชั้นฐานข้อมูล** ไม่ใช่แค่ซ่อนปุ่ม (เปิดครบ 30 ตาราง)
- หน้าร้าน → ตะกร้า → checkout → PromptPay QR → แนบสลิป → ยืนยันเงิน → ออกใบเสร็จ
- **สั่งจองล่วงหน้า**: คิวใครก่อนได้ก่อน · จ่ายของอัตโนมัติเมื่อของเข้า · เติมต้นทุนย้อนหลัง
- รายงานกำไรแยกช่องทาง + ส่วนต่างค่าส่ง + export CSV
- แจ้งเตือนเข้า LINE ผ่านกล่องข้อความ (outbox) พร้อม cron เก็บตกที่ส่งพลาด
- ลืมรหัสผ่านหลังบ้าน → ส่งลิงก์ทางอีเมล

## ความปลอดภัย

**ที่กันไว้แล้ว** — `.env.local` · `.dev.vars` · `supabase/.temp/` · `ความลับ-ห้ามขึ้น-git/`
ถูก gitignore และสคริปต์ deploy มีด่านตรวจว่าไม่มีไฟล์ลับติดไปกับ commit

**ที่ต้องจัดการ** — คีย์ ShipPop (API key, username, password) เคยถูก commit ขึ้น git
การลบออกวันนี้ไม่ลบออกจากประวัติ **ควรขอคีย์ใหม่และเปลี่ยนรหัสผ่านกับ ShipPop**

รหัสผ่านใน `book-shop/supabase/seed.sql` เป็นบัญชีทดสอบสำหรับฐานข้อมูลในเครื่องเท่านั้น
ไฟล์นั้นไม่ถูกส่งขึ้น production (`supabase db push` ไม่รวม seed)
